# ゆく育 ダメージ計算機（非公式）

スマホゲーム『ゆっくり育てていってね！』の与ダメージを計算するWebツールです。
非公式Wiki（計算式・スキル・必殺技ページ）の情報をもとに作成しています。

**公開ページ:** https://pillowknight.github.io/yukuiku-calc/

## できること
- キャラ・武器・ゆくせさり・必殺技・スキルを選んで、通常攻撃／スキル／必殺技の与ダメージ（通常・クリティカル・期待値）を計算
- 他者から受けるバフ（必殺技バフ・スキル・ゆくせさり）の指定
- バフごとのON/OFF、発動具合の調整
- 任意バフ・攻撃の係数の手動入力（係数は置き換え）
- 与ダメージの保存と比較、画像（PNG）での書き出し

## 使い方
ページを開いて、上から順にキャラ等を選ぶだけです。
入力内容はブラウザ内（localStorage）にのみ保存され、サーバーには送信されません。
保存した与ダメージのデータはページを閉じると消えるため、必要なら画像で残してください。

## 注意
- 非公式ツールです。ゲーム運営とは関係ありません。
- 計算式・数値はWikiの記載および、作者手動での確認に基づくため、ゲームのアップデートや記載の誤りにより実際の値と異なる場合があります。
- 一部の攻撃（輪入道LMなど）は係数データ未確認です。
